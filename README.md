# 💈 Barbearia 47

Projeto demonstrativo de site responsivo desenvolvido para representar a presença digital de uma barbearia, com foco em apresentação dos serviços, experiência do usuário e contato rápido com o estabelecimento.

## 🚀 Funcionalidades

- Layout responsivo
- Apresentação de serviços e preços
- Galeria de imagens
- Seção sobre a barbearia
- Avaliações demonstrativas
- Localização e horário de funcionamento
- Contato direto pelo WhatsApp
- Menu mobile
- Animações e efeitos de rolagem

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## 🌐 Projeto online

🔗 https://barbearia-47.vercel.app/

## 📌 Sobre o projeto

A Barbearia 47 foi desenvolvida como projeto demonstrativo para portfólio, simulando um site profissional para um negócio local do setor de barbearia.

O objetivo foi criar uma página moderna, responsiva e de fácil navegação, permitindo que o cliente encontre serviços, preços, localização e formas de contato em poucos passos.
